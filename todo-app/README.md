# Todo App

אפליקציית Todo מינימלית ב־React, TypeScript ו־Vite.

## הרצה מקומית

```bash
npm install
npm run dev
```

## GitHub Pages

1. יש ליצור repository בשם `agent-demo-taskboard` ולהעלות אליו את שתי תיקיות הפרויקט.
2. ב־GitHub יש לפתוח **Settings → Pages** ולבחור תחת **Source** באפשרות **GitHub Actions**.
3. כל push לענף `main` יבנה ויפרסם את האפליקציה אוטומטית.

כתובת האתר תהיה: `https://<username>.github.io/agent-demo-taskboard/`.
