# Todo App

A minimal Todo app built with React, TypeScript and Vite. It is the app the coding agent works on in the demo.

## Running locally

```bash
npm install
npm run dev
```

## GitHub Pages

1. Create a repository named `agent-demo-taskboard` and push both project folders to it.
2. In GitHub, open **Settings → Pages** and choose **GitHub Actions** under **Source**.
3. Every push to `main` builds and publishes the app automatically.

The site is served at `https://<username>.github.io/agent-demo-taskboard/`.
